# Погода Краков — Запуск локально

## Быстрый старт

Файл использует `fetch()` для обращения к Open-Meteo API,
поэтому нужен HTTP-сервер (открытие `file://` не сработает).

### Вариант 1 — Node.js (рекомендуется)

```bash
cd /home/user/doraby.com
npx serve dorogenskaya.com/new -p 8080
```

Затем открыть в браузере:
```
http://localhost:8080/weather.html
```

### Вариант 2 — Python

```bash
cd /home/user/doraby.com/dorogenskaya.com/new
python3 -m http.server 8080
```

Открыть:
```
http://localhost:8080/weather.html
```

## Что показывает приложение

| Блок | Описание |
|------|----------|
| **Прогноз 14 дней** | Максимальная и минимальная температура, иконка погоды, осадки |
| **Архив за месяц** | Все дни текущего месяца — прошедшие (факт) + будущие (прогноз) |
| **График год** | Оранжевая линия = 2026 (факт + прогноз), серая пунктирная = среднее 2021–2025 |

- **Прогноз:** `api.open-meteo.com/v1/forecast`
- **Архив:** `archive-api.open-meteo.com/v1/archive`
